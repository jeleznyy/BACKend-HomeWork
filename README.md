# Лабораторная работа 2

ФИО: Иванов Олег Петрович

Группа: Б9124-02.03.01мо

HTTP-сервис проката велосипедов. Java 21, Maven, Spring Boot.

Выполненные задания:
- API велосипедов, клиентов и проката перенесён на Spring Boot. Данные хранятся в памяти.
- Добавлены юнит-тесты правил проката без запуска Spring.

Запуск из папки проекта: `mvn spring-boot:run`

Проверка в Git Bash: `bash requests.sh`
Перед проверкой нужно перезапустить сервер.

Запуск тестов: `mvn test`
